User Workflows
==============

FAX can be used as a Python library, a TOML-driven CLI, and a set of research
example scripts. This page maps common research tasks to the current commands
and outputs.

Installation Check
------------------

After installing the package, verify the CLI and import path:

.. code-block:: bash

   fax --help
   python -c "import fax; print(fax.__version__)"

The package supports Python 3.10 and newer. On Python 3.10, FAX uses
``tomli`` as the TOML reader fallback; on Python 3.11 and newer it uses the
standard-library ``tomllib``.

Run a Minimal Continuum Case
----------------------------

.. code-block:: bash

   fax examples/minimal.toml --dry-run
   fax continuum examples/minimal.toml --json

Expected outputs include:

* console progress with phase names and timings,
* JSON/Markdown summaries in the configured output directory,
* continuum branch data,
* optional plots generated by follow-up plotting commands.

Run Global Eigenmodes
---------------------

.. code-block:: bash

   fax eigenmodes examples/global_eigenmodes.toml
   fax plot-global outputs/global_eigenmodes/eigenmodes --output-dir outputs/global_eigenmodes/figures

The eigenmode workflow writes:

* ``global_eigenmode_summary.json`` with operator, geometry, harmonic, residual,
  and frequency metadata,
* ``global_eigenmode_metrics.json`` with residual and mode-content metrics,
* ``global_eigenmodes.csv`` with reported eigenvalues, frequencies, and
  residuals,
* ``global_mode_structures.csv`` with ``(mode, surface, harmonic)`` amplitudes.

For a real Boozer geometry, set ``equilibrium.boozmn`` in the TOML file. FAX
then builds the real-Boozer radial block operator; without a ``boozmn`` file it
uses the validated scalar radial-envelope workflow for analytic or VMEC-profile
fixtures.

Run Validation Gates
--------------------

.. code-block:: bash

   fax validate examples/minimal.toml
   fax validate examples/minimal.toml --tag metric --json
   fax validate examples/minimal.toml --tag boozer --tag global

Use ``fax maturity`` to inspect what still blocks final no-proxy/full-physics
status:

.. code-block:: bash

   fax maturity
   fax maturity --json

Use ``fax benchmark-manifest`` to inspect which local STELLGAP/AE3D artifacts
are known and hashable:

.. code-block:: bash

   fax benchmark-manifest
   fax benchmark-manifest --json --hashes

Use ``fax kinetic-parity`` for FAR3D/CAS3D-K growth-rate packets. The command
requires held-out validation cases before it can pass:

.. code-block:: bash

   fax kinetic-parity kinetic_dataset.json predictions.json
   fax kinetic-parity kinetic_dataset.json predictions.json --json

Use tags to focus on one layer while developing. Before pushing or making a
publication figure, run the full local suite described in :doc:`development`.

Run Convergence Sweeps
----------------------

.. code-block:: bash

   fax convergence examples/landreman_paul_qa_lowres.toml
   fax plot-convergence outputs/convergence --output-dir outputs/figures

Convergence outputs include radial, angular, and mode-resolution tables. The
coarsest rows are compared against the finest row after radial interpolation
where needed. Use these reports before trusting any VMEC-backed plot.

Run Benchmarks
--------------

.. code-block:: bash

   fax benchmark examples/minimal.toml --family global-block
   fax benchmark examples/minimal.toml --family global-matrix-free --family global-krylov

Benchmark outputs include JSON, CSV, and Markdown files. Separate cold compile
time from warmed runtime when interpreting JAX numbers. Do not report speedups
without the corresponding validation metric.

Generate Publication-Style Figures
----------------------------------

The figure scripts are executable examples:

.. code-block:: bash

   python examples/research/basic_alfven_gap_map.py
   python examples/research/global_gap_fastion_screen.py
   python examples/research/boozmn_global_3d_eigenmodes.py
   python examples/research/boozmn_differentiable_design_study.py
   python examples/research/publication_figure_suite.py

For a first community run without external files, start with
``basic_alfven_gap_map.py``, ``global_gap_fastion_screen.py``, and selected
``publication_figure_suite.py`` cases such as ``--case 01 --case 02``. Real
``boozmn`` and STELLGAP/AE3D examples require the optional local artifacts
documented in :doc:`research_examples`.

After regenerating figures, run:

.. code-block:: bash

   python tools/qa_figures.py

The QA tool checks that figures are not blank and that rendered PNG/SVG files
have plausible content.

Use FAX from Python
-------------------

Profile-mode sensitivity example:

.. code-block:: python

   import jax
   import jax.numpy as jnp
   from fax.equilibrium import analytic_circular_tokamak
   from fax.optimization import radial_mode_frequency_vector

   geometry = analytic_circular_tokamak(radial_points=32)
   params = jnp.zeros(3)

   def first_frequency(p):
       return radial_mode_frequency_vector(
           p,
           geometry=geometry,
           harmonic=(2, 1),
           mode_count=1,
       )[0]

   print(first_frequency(params))
   print(jax.grad(first_frequency)(params))

Real-Boozer isolated-mode objective:

.. code-block:: python

   import jax.numpy as jnp
   from fax.boozer import read_boozmn_geometry
   from fax.optimization import boozer_global_isolated_mode_frequency_hz

   geometry = read_boozmn_geometry("boozmn.nc")
   harmonics = jnp.asarray([[1.0, 0.0], [2.0, 1.0]])
   params = jnp.zeros(3)

   f0 = boozer_global_isolated_mode_frequency_hz(
       params,
       geometry=geometry,
       harmonics=harmonics,
       mass_density=3.4e-8,
       mode_index=0,
   )

Mode-family or crossing-safe objective:

.. code-block:: python

   from fax.optimization import boozer_global_cluster_mean_frequency_hz

   f_cluster = boozer_global_cluster_mean_frequency_hz(
       params,
       geometry=geometry,
       harmonics=harmonics,
       mass_density=3.4e-8,
       start_index=0,
       stop_index=2,
   )

Use the isolated objective only when the target mode is separated. Use the
cluster objective near crossings or when branch labels exchange.

Typical Research Tasks
----------------------

Build an Alfvén continuum map
   Use ``fax continuum`` or ``continuum_branch_matrix`` for fast profile maps.
   Use Boozer local 3-D matrices for stellarator coupling studies.

Find BAE/TAE/EAE markers
   Use ``examples/research/basic_alfven_gap_map.py`` and the helpers in
   ``fax.gap_models``. Treat the result as an analytic screen until cross-code
   gap-width gates are added.

Compute global radial eigenmodes
   Use ``fax eigenmodes`` for TOML-driven artifact generation. Use
   ``solve_radial_eigenmodes`` for scalar profile fixtures and
   ``solve_radial_block_eigenmodes`` for direct Boozer harmonic block problems.

Check fast-ion resonance overlap
   Use ``eigenfunction_fast_ion_drive`` or the higher-level optimization
   screens. Interpret current outputs as drive indicators, not kinetic growth
   rates.

Perform sensitivity analysis
   Use JAX ``grad``/``jacfwd`` on the documented objective functions. Record
   finite-difference checks for publication.

Perform uncertainty propagation
   Use ``linearized_radial_mode_uncertainty`` or
   ``linearized_boozer_global_mode_uncertainty`` with a covariance matrix.

Run inverse design
   Use ``radial_mode_inverse_design`` or ``boozer_global_mode_inverse_design``
   for small transparent gradient-descent examples. For production, plug the
   same objective into a more capable optimizer after validation gates pass.

Output Discipline
-----------------

For every research run, save:

* input TOML or script,
* FAX commit,
* external geometry artifact paths and hashes,
* validation report,
* convergence report,
* benchmark report when runtime is discussed,
* figures and figure manifest.

This is the minimum packet needed for a paper, review response, or future
restart of the analysis.

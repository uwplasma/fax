fax
===

``fax`` is a planned differentiable JAX code for Alfvén eigenmodes, fast-ion
drive, continuum gaps, and toroidal/helical coupling in stellarators.

The code is being designed to consume ``vmec_jax`` equilibria directly, and to
use ``booz_xform_jax`` when Boozer coordinates are required by the selected
model.

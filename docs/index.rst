FAX
===

FAX computes shear-Alfvén continua and Alfvén eigenmodes of stellarators in
JAX. It reads Boozer-coordinate geometry from ``boozmn`` files, from VMEC
``wout`` data through ``booz_xform_jax``, or directly from a ``vmex``
equilibrium, so frequencies can be differentiated with respect to the plasma
boundary.

Function Map
============

This page is a curated map of the public API. The full autogenerated reference
is in :doc:`api`; this page explains which functions to use for common tasks.

Configuration and CLI
---------------------

``fax.config.load_config``
   Read a TOML configuration into a ``FaxConfig`` object. Python 3.10 uses the
   ``tomli`` fallback, while newer Python versions use ``tomllib``.

``fax.runner.run``
   Execute the high-level run path for a parsed config.

``fax.workflows``
   Contains CLI workflow helpers for continuum, global eigenmodes,
   convergence, validation, and benchmark commands.

Equilibrium Helpers
-------------------

``analytic_cylinder``
   Uniform large-aspect-ratio fixture for exact continuum tests.

``analytic_circular_tokamak``
   Smooth profile fixture for gap maps, radial modes, sensitivity, and UQ.

``from_vmec_wout``
   Minimal VMEC ``wout`` profile adapter used by Landreman-Paul QA examples.

Mode and Continuum Helpers
--------------------------

``stellarator_mode_family``
   Build harmonic families with field-period-aware toroidal mode numbers.

``local_continuum_frequency_hz``
   Compute one local branch for a profile geometry.

``continuum_branch_matrix``
   Compute a radial-by-harmonic branch matrix.

Metric Operators
----------------

``MetricGeometry``
   Angular-grid geometry pytree used by local continuum matrices.

``metric_from_equilibrium``
   Lift analytic profile geometry to the uniform metric fixture.

``metric_from_vmec_wout``
   Reconstruct metric inputs from VMEC Fourier coefficients.

``metric_continuum_matrices``
   Assemble local Hermitian ``K`` and ``M`` matrices.

``generalized_hermitian_eigensystem``
   Dense JAX generalized Hermitian eigensolve.

``generalized_eigen_residual_norms``
   Relative residual checker for ``Kx=lambda Mx``.

``generalized_hermitian_eigenvalue_sensitivity``
   Explicit isolated-eigenpair first-order derivative.

``generalized_hermitian_isolated_eigenvalue``
   Dense value path with custom-JVP isolated eigenvalue derivative.

``generalized_hermitian_eigencluster_sensitivity``
   Subspace derivative diagnostics for repeated or near-crossing clusters.

``generalized_hermitian_cluster_mean_eigenvalue``
   Cluster-mean value path with custom-JVP derivative.

Boozer Geometry
---------------

``read_boozmn_geometry``
   Read real ``boozmn`` geometry harmonics.

``run_booz_xform_jax_geometry_from_wout``
   Run local ``booz_xform_jax`` from a VMEC ``wout`` file.

``run_booz_xform_jax_geometry_from_wout_data``
   Run local ``booz_xform_jax`` from an in-memory VMEC ``wout`` object.

``run_vmec_jax_fixed_boundary_boozer_geometry``
   Smoke-test bridge from VMEC input to live ``vmec_jax`` solve to Boozer
   geometry.

``boozer_geometry_jacobian_identity_error``
   Check ``sqrt(g) |B|^2 = G + iota I`` on sampled Boozer grids.

``boozer_3d_continuum_matrices``
   Assemble local real-Boozer shear-Alfven continuum matrices.

Global Modes
------------

``constant_radial_problem``
   Scalar exact-spectrum fixture.

``radial_problem_from_equilibrium``
   Build scalar radial envelope problem from a profile equilibrium.

``constant_radial_block_problem``
   Block exact-spectrum fixture.

``radial_block_problem_from_boozer_geometry``
   Build the global radial block operator from real Boozer geometry.

``solve_radial_eigenmodes``
   Dense scalar radial eigensolve.

``solve_radial_block_eigenmodes``
   Dense global radial block eigensolve.

``solve_radial_block_eigenmodes_sparse``
   SciPy sparse/Krylov reference solver for larger block problems.

``run_global_eigenmodes``
   TOML-driven workflow that writes global eigenfrequency and mode-structure
   artifacts for scalar profile or real-Boozer radial block operators.

``radial_block_stiffness_matvec`` and ``radial_block_mass_matvec``
   JAX-native matrix-free operator application.

``radial_block_eigenvalue_sensitivity``
   Explicit radial-block isolated eigenvalue tangent contraction.

``radial_block_isolated_omega2``
   Custom-JVP isolated radial-block eigenvalue.

``radial_block_cluster_mean_omega2``
   Custom-JVP radial-block cluster mean for crossings.

Gap Models
----------

``basic_alfven_gap_map``
   Fast BAE/TAE/EAE demonstration object.

``tae_gap_estimate``
   Analytic TAE crossing location and center frequency.

``bae_accumulation_frequency_hz``
   Fluid-order BAE accumulation marker.

Fast-Ion Screens
----------------

``FastIonPopulation``
   Radial profiles for reduced fast-ion resonance diagnostics.

``resonance_mismatch_hz``
   Compute ``f_mode - n f_phi - l f_theta``.

``reduced_fast_ion_drive``
   Pressure-gradient-weighted Lorentzian drive indicator.

``eigenfunction_fast_ion_drive``
   Project reduced drive onto global eigenfunction intensity.

Optimization
------------

``frequency_window_penalty``
   Smooth exclusion-window penalty.

``radial_mode_frequency_vector`` and ``radial_mode_frequency_jacobian``
   Profile-design frequency map and sensitivity matrix.

``linearized_radial_mode_uncertainty``
   Covariance propagation with ``J C J^T``.

``radial_mode_inverse_design``
   Transparent gradient-descent inverse-design example.

``boozer_global_mode_frequency_vector``
   Real-Boozer global frequency map.

``boozer_global_isolated_mode_frequency_hz``
   Single isolated mode for design studies.

``boozer_global_cluster_mean_frequency_hz``
   Mode-family/crossing-safe cluster mean.

``boozer_global_cluster_mean_avoidance_objective``
   Smooth cluster-mean exclusion-window objective.

``boozer_fast_ion_risk_objective``
   Real-Boozer frequency-window plus reduced fast-ion growth risk.

``boozer_pipeline_mode_avoidance_objective``
   Builder-based end-to-end objective.

``boozer_pipeline_isolated_mode_avoidance_objective``
   Builder-based isolated-mode objective.

``boozer_pipeline_cluster_mean_avoidance_objective``
   Builder-based crossing-safe cluster objective.

Validation, Figures, and Benchmarks
-----------------------------------

``registered_validation_gates``
   Validation registry with metadata, tolerances, citations, commands, and
   tags.

``run_validation_gate`` and ``run_validation_suite``
   Programmatic validation execution.

``plot_basic_alfven_gap_map``
   Plot the fast BAE/TAE/EAE example.

``plot_global_eigenmode_artifacts``
   Plot ``fax eigenmodes`` frequency, residual, envelope, and harmonic-content
   artifacts.

``run_named_benchmark_family``
   Run a named benchmark family and return structured runtime data.

Preferred Import Pattern
------------------------

For research scripts, import from submodules rather than the top-level package
when the ownership is clear:

.. code-block:: python

   from fax.boozer import read_boozmn_geometry
   from fax.global_modes import radial_block_problem_from_boozer_geometry
   from fax.optimization import boozer_global_cluster_mean_frequency_hz

The top-level ``fax`` namespace exports common classes and functions for
interactive use, but submodule imports make scripts easier to audit.
